## 9. 注意事项

1. **执行顺序**：先 §1 一键安装 → §7 对象数 → §2 残留 → §3 冒烟 → §4 等价 → §5 Gate → §6 纪律
   - **§1 必须最先**：若一键装不上，后面都不用做
2. **schema 隔离**：所有测试用 `--schema manual_test_20261012`，**不**碰默认 `oracle_poc_verify`
3. **不要 commit 测试日志**：测试记录放 `/tmp/`，不在仓库内
4. **测试中发现新缺陷**：记到 `/tmp/manual_test_20261012.md`，**不直接改代码**——回头开新 P* 任务
5. **psql 中文乱码**：在 Windows 用 `chcp 65001` 切 UTF-8，或设置 `PGCLIENTENCODING=UTF8`
6. **重复执行**：每次跑验证脚本前备份原报告（防覆盖污染基线）
7. **三个脚本各司其职**：
   - `convert_oracle_poc.py --clean`：重转产物（开发用）
   - `install_oracle_poc.py install`：装 PG（手测用）
   - `verify_oracle_poc_output.py`：跑 Gate 报告（会覆盖产物验证报告）
