## 统一入口

### `pg.py` ⭐ 推荐

**唯一推荐使用的入口**, 整合所有转换和验证功能.

```bash
# 查看帮助
python pg.py --help
python pg.py convert --help
python pg.py verify --help

# 转换
python pg.py convert ddl         # 转换 DDL
python pg.py convert view        # 转换 VIEW
python pg.py convert plsql       # 转换 PL/SQL
python pg.py convert pkg         # 转换 PACKAGE_BODY
python pg.py convert stubs       # 生成包桩
python pg.py convert all         # 一键转换所有

# 验证
python pg.py verify type         # 类型映射自检
python pg.py verify ddl          # DDL 79 项
python pg.py verify equiv        # 全量等价 44 项
python pg.py verify proc         # 存储过程 49 项
python pg.py verify biz          # 业务覆盖 93 项
python pg.py verify view         # VIEW 验证
python pg.py verify col          # DDL 514 列回归
python pg.py verify all          # 一键验证

# 信息
python pg.py info                # 查看项目状态
```

## 详细使用说明

### 1. `convert/ddl_converter.py`

**功能**: Oracle 表 DDL → PostgreSQL 表 DDL

```bash
# 转换所有表 (默认从 source/table/)
python convert/ddl_converter.py --all

# 转换单个文件
python convert/ddl_converter.py --input source/table/GKBTZOKUGARA.SQL

# 批量转换指定目录
python convert/ddl_converter.py --input source/table/ --output out/ddl/
```

**输出**: `out/ddl/<table_name>.pgsql`

**覆盖**:
- ✅ NUMBER, VARCHAR2, NVARCHAR2, CHAR, CLOB 类型转换
- ✅ NOT NULL, DEFAULT, CHECK 约束
- ✅ PRIMARY KEY, FOREIGN KEY, UNIQUE
- ✅ 表/列 COMMENT
- ⚠️ 索引需手工处理

---

### 2. `convert/view_converter.py`

**功能**: Oracle VIEW → PostgreSQL VIEW

```bash
python convert/view_converter.py --all
python convert/view_converter.py --input source/view/GKBVEUCGAKUREIBO.SQL
```

**覆盖**:
- ✅ 移除 FORCE 关键字
- ✅ 移除 `/*+ HINT */` 注释
- ✅ DECODE → CASE WHEN
- ✅ 移除 COMMENT ON 语句
- ✅ 移除末尾 / 符号
- ⚠️ Oracle `(+)` 外连接标记为 `/* OUTER_JOIN_PLUS */` 需手动转换
- ❌ CONNECT BY 需手动改写为 WITH RECURSIVE

**验证**: `python scripts/verify_views.py`

---

### 3. `convert/plsql_converter.py`

**功能**: 独立 PL/SQL 函数/过程 → PostgreSQL 函数/过程

```bash
# 转换所有
python convert/plsql_converter.py --all

# 转换单个
python convert/plsql_converter.py --input source/function/GKBFKGKNCDHK.SQL

# 转换 + 冒烟测试
python convert/plsql_converter.py --all --smoke
```

**覆盖**:
- ✅ IN/OUT 参数映射
- ✅ RETURN NUMBER → RETURNS TABLE
- ✅ IS 声明段 → DECLARE
- ✅ NVL → COALESCE
- ✅ NUMBER/INTEGER 类型映射
- ⚠️ 嵌套函数/%ROWTYPE → 调用专用策略

---

### 4. `convert/convert_package_body.py`

**功能**: Oracle PACKAGE_BODY → PostgreSQL 函数簇

```bash
python convert/convert_package_body.py --all
python convert/convert_package_body.py --pkg GKBPA00081
```

**环境变量**:
- `PG_SOURCE_BASE`: Oracle 源路径 (默认: `gkb/01.release/`)
- `PG_FUNC_PREFIX`: 函数前缀 (默认: `gkbpkg`)

### 6. `convert/oracle_pg_rules.py`

**功能**: 通用 L1 规则库 (库, 非命令行工具)

```python
from oracle_pg_rules import convert_sql
pg_sql = convert_sql("SELECT NVL(a, b) FROM DUAL WHERE SYSDATE > TRUNC(SYSDATE)")
```

**规则覆盖** (基于 OpenTool/oracle-to-pg-conversion-foundations.md):
- ✅ NVL → COALESCE
- ✅ DECODE → CASE
- ✅ SYSDATE → CURRENT_DATE
- ✅ SYSTIMESTAMP → CURRENT_TIMESTAMP
- ✅ INSTR → STRPOS
- ✅ DBMS_OUTPUT → RAISE NOTICE
- ✅ EXECUTE IMMEDIATE → EXECUTE
- ✅ DUAL 删除
- ✅ `||` NULL 语义
- ⚠️ ROWNUM → LIMIT (简化版)
- ❌ SQLCODE/SQLERRM (未实现, 908 处)
- ❌ DBMS_SQL 重写 (未实现, 2987 处)

## 快速决策树

```
你是谁?
├─ 普通用户 (想跑转换+验证)
│   └─ python pg.py convert all && python pg.py verify all
│
├─ 开发者 (想修改转换器)
│   └─ 阅读 OpenTool/oracle-to-pg-conversion-foundations.md
│       └─ 修改 convert/oracle_pg_rules.py
│           └─ python pg.py verify biz  # 验证修改
│
├─ 其他项目使用者 (想转换自己项目)
│   └─ 配置 PG_SOURCE_BASE 后运行: python pg.py convert all
│
└─ 调试者 (某个对象转换失败)
    └─ 查看 docs/PLSQL转换失败分析报告_237-9.md
        └─ python pg.py convert plsql   # 重跑转换
        └─ python pg.py verify plsql 业务相关测试
```
