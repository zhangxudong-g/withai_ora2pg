* 概述

本文档基于 ora2pg_py_perlstyle 引擎（/perlstyle_engine.py/）的实际实现，
生成 Oracle → PostgreSQL 各种对象的转换对照表。

源代码统计：
- ~perlstyle_engine.py~: 4307 行
- ~_TYPE_MAP~: 30+ 类型映射规则
- 函数转换: 20+ 内置函数
- PL/SQL → plpgsql 转换: 14 个阶段

* 五、函数/过程 (FUNCTION/PROCEDURE) 转换

调用链 (~convert_function~)：

#+BEGIN_EXAMPLE
1. 处理 PRAGMA (AUTONOMOUS_TRANSACTION/RESTRICT_REFERENCES/SERIALLY_REUSABLE)
2. 移除注释
3. 解析函数头 (声明块 + 代码块)
4. 转换 OUT 参数
5. 内联嵌套函数 (PG 不支持)
6. 应用类型映射
7. REF CURSOR 转换
8. 执行 PL/SQL 转换流水线
9. PERFORM/CALL 语义处理
10. 移除物理属性
11. 应用 RAISE NOTICE 等
12. 嵌套函数内联
13. 包裹为 CREATE FUNCTION
#+END_EXAMPLE

** PRAGMA 处理

| Oracle PRAGMA | PostgreSQL 处理 |
|---------------|-----------------|
| ~PRAGMA AUTONOMOUS_TRANSACTION~ | 注释（不支持） |
| ~PRAGMA RESTRICT_REFERENCES(...)~ | 删除 |
| ~PRAGMA SERIALLY_REUSABLE~ | 删除 |

** 参数模式转换

| Oracle 模式 | PostgreSQL |
|-------------|------------|
| ~IN~ | ~IN~ (或省略) |
| ~OUT~ | ~OUT~ (转换为 RETURNS TABLE 或 OUT 参数) |
| ~IN OUT~ | ~INOUT~ |

** 嵌套函数处理

Oracle 允许嵌套函数（PG 不支持）。引擎的处理：
1. ~_extract_nested_functions~ - 提取嵌套函数
2. ~_inline_nested_functions~ - 移除并展开调用

调用模式：
- ~IF FUNC() THEN~ → ~IF value /* INLINED: FUNC */ THEN~
- ~IF FUNC = FALSE THEN~ → ~/* TODO: FUNC - complex */ IF = FALSE THEN~
- ~x := FUNC()~ → ~x := value; /* INLINED: FUNC */~

* 七、触发器 (TRIGGER) 转换

Oracle 触发器 → PG 触发器函数 + CREATE TRIGGER

#+BEGIN_SRC sql
-- Oracle
CREATE OR REPLACE TRIGGER trig_name
BEFORE INSERT OR UPDATE ON tab
FOR EACH ROW
WHEN (new.col > 0)
BEGIN
  :NEW.col := :NEW.col + 1;
END;
#+END_SRC

↓

#+BEGIN_SRC sql
-- PostgreSQL
CREATE OR REPLACE FUNCTION trig_name() RETURNS TRIGGER AS $$
BEGIN
  NEW.col := NEW.col + 1;
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trig_name BEFORE INSERT OR UPDATE ON tab
FOR EACH ROW WHEN (new.col > 0)
EXECUTE FUNCTION trig_name();
#+END_SRC

* 二十二、错误检测模式

** 检测的逻辑错误（Level 1）

静态分析会检测以下可能导致逻辑错误的模式：

| 错误模式 | 示例 | 检测正则 |
|----------|------|----------|
| ~IF NULL~ | ~IF NULL THEN~ | ~IF\s+NULL\b~ |
| ~IF TRUE with TODO~ | ~IF TRUE /* TODO */~ | ~IF\s+TRUE\s+/\*\s*replace~ |
| ~= NULL THEN~ | ~WHERE col = NULL~ | ~=*\s*NULL\s+THEN~ |
| ~:= NULL~ | ~x := NULL;~ | ~:=\s*NULL\s*;~ |
| ~IF NEEDS_MANUAL~ | ~IF NEEDS_MANUAL THEN~ | ~IF\s+\?\s*NEEDS_MANUAL~ |

** 检测的占位符（Level 1）

| 占位符 | 说明 |
|--------|------|
| ~/* TODO: ... */~ | 需要手动处理 |
| ~/* INLINED: ... */~ | 已内联 |
| ~/* BEGIN INLINED: ... */~ | 内联开始 |
| ~/* END INLINED: ... */~ | 内联结束 |
| ~NEEDS_MANUAL~ | 需要手动处理 |

** 检测的 Oracle 残留（Level 1）

| 残留 | 严重性 |
|------|--------|
| ~VARCHAR2~, ~NVARCHAR2~ | 中（类型未转换） |
| ~NUMBER~ | 中 |
| ~TO_CHAR~, ~TO_NUMBER~ 等 | 低（PG 也支持） |
| ~CONNECT BY~ | 高（语法不兼容） |
| ~ROWNUM~ | 中 |
| ~%FOUND~, ~%NOTFOUND~ | 低（PG 兼容） |
| ~:NEW~, ~:OLD~ | 中（trigger 伪记录） |
| ~RETURN type IS~ | 高（无效语法） |
| ~CREATE PACKAGE BODY~ | 高（PG 不识别） |
