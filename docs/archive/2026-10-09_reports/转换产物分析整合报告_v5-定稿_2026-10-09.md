## 一、四方来源对比结论（一致性裁决）

| 来源 | 基线 | 关键口径 | 状态 |
|---|---|---|---|
| v1 逐一分析 | 当前产物静态全文 + pglast + grep | 🟢2/🟡4/🔴7 | ✅ 判定被本版沿用 |
| `docs/CONVERSION_ISSUES_ANALYSIS.md` | 旧一轮快照（57 失败 / 88.6） | 多项 P0/P1 已修复 | ⚠️ 整体过期 |
| `HANDOFF.md`（commit 3012327） | 与当前产物同基线（23~24 失败 / 86.6~87.0） | 含 7 项修复记录 | ◐ 大体一致，2 处漏判（见下） |
| v3/v4 整合报告 | 当前产物实测 | 与 v1 同判定 + 纠偏 | ✅ 合并进本版 |

**一致性约 85%，经逐行 grep/sed 实测后的裁决：**

1. **TRIGGER 分歧（最重要）**：ISSUES 说"缺 END IF/$$/RETURN 位置错"→ 已被 commit 1bbc132 修复，该描述过时；HANDOFF 据此记 `2/2 ✅` → **只对了前半**。真实遗留：`TRIGGER/00_TRIGGER.sql:2` 仍有 `STUDENT_MST.STUDENT_NO%TYPE`，plpgsql 延迟解析使其**安装成功但宿主表首次 INSERT 即炸**。DATA 49/49 能过只是因为 STUDENT_MST 尚未绑触发器。
2. **VIEW V_STUDENT_SCORE 分歧**：HANDOFF 记"49085b5 修复后 VIEW 18/18"→ **与入库产物不符**。实测产物中连接条件 `SB.TEACHER_CD = T.TEACHER_CD` 被挂在 `SUBJECT_MST SB` 的 ON 上、而 `TEACHER_MST T ... ON TRUE` 在其后才出现——引用未 join 的表（PG 报 42P01"丢失 FROM 子句项"），且 T 变无条件笛卡尔 LEFT JOIN，教师名会错配。**教训：修复 commit ≠ 产物已更新，每次引擎修复后必须重新生成产物并全量复验。**
3. **一键脚本中断点**：按 `00_CREATE_ALL_PG.sql` 实际顺序（TABLE→SEQUENCE→TYPE→**VIEW(第4)**→TRIGGER→FUNCTION→PROCEDURE→PACKAGE→PACKAGE_BODY→SYNONYM→DATA），`\set ON_ERROR_STOP on` 下预计**第 4 步 VIEW 即中断**（比 HANDOFF 说的第 7 步更早）。
4. **数字口径**：86.6/B/24 失败为最新同批次权威值；88.6/57 属旧轮次；HANDOFF 内部 86.6 vs 87.0 差异来自先后两轮验证，不影响结论方向。
5. **v2 一批问题确认已消失**（grep 0 命中，勿重复投入）：GROUP BY 字面量、NVARCHAR2[]、SYS_REFCURSOR、OUT 参数未声明（已转 INOUT）、`s.`→current_setting 误包表名、视图 (+) 字符残留（现为"改写错乱"而非"未改写"）。
6. **v1 自我纠错**：V_DEPENDENCY_GRAPH 的 (+) 丢失描述有误（该视图当前无此问题）；SEQUENCE MAXVALUE 封顶带警告注释，属已知设计决策而非盲目截断。

## 四、问题归类（A–H，定稿口径）

- **A 嵌套子程序文本内联损坏**（8 处 INLINED + 孤儿 END）→ 废弃内联，走 lift（T10）
- **B TODO 空壳桩**（28 处）→ AI Agent 二次转换 + validate_pg 硬校验回灌（T11）
- **C Oracle 专有语法残留**（%TYPE×5、BULK COLLECT/FORALL、PIPE ROW、UTL_FILE、SQLCODE 等）→ 规则补映射（T5）+ Agent 专项（T12）
- **D %SUBQUERY 占位符未回填**（3 处，静默丢数据，最高危）→ restore 兜底断言（T3）
- **E PG 签名/事务规则违反**（INOUT+RETURNS、函数内 COMMIT、`BEGIN set_config` 拼接）→ 确定性规则 + L2 静态检查（T12）
- **F 类型模型不等价**（OBJECT TYPE 方法、TABLE OF、REF CURSOR、SELF_xxx）→ AST 重新建模（T9）
- **G (+) 外连接改写算法错误**（非残留而是改错）→ 结构化建图+拓扑排序（T4）★优先级上调
- **H 语义退化需业务确认**（GTT、MAXVALUE/CYCLE、SYNONYM→VIEW、UTL_FILE 去向）→ 登记《迁移注意事项》（T6）
