## 二、手册章节对照实现

### 2.1 数据类型映射（§5）

| Oracle 类型 | 手册要求 | 当前实现 | 状态 |
|---|---|---|---|
| `NUMBER(p,s)` → `numeric(p,s)` | 精度验证 | `perlstyle_engine` 有映射 | ✅ |
| `NUMBER` → `bigint/integer` | 按范围选择 | **硬编码为 bigint** | 🟡 缺范围分析 |
| `VARCHAR2` → `varchar` | 按长度 | 有映射 | ✅ |
| `DATE` → `timestamp(0)` | 含时分秒 | 保留 `DATE` | 🟡 需确认 |
| `%TYPE` → 查表展开 | 建字典替换 | ✅ P2-2 已实现 | ✅ |
| `%ROWTYPE` | 查表/复合类型 | 部分处理 | 🟡 |

**缺失**：`BINARY_FLOAT/DOUBLE`、`TIMESTAMP WITH TIME ZONE`、`INTERVAL` 映射

### 2.2 SQL 语法和语义差异（§7）

| 特性 | 手册要求 | 当前实现 | 状态 |
|---|---|---|---|
| `NVL` → `COALESCE` | 函数映射 | ✅ | ✅ |
| `DECODE` → `CASE` | **NULL匹配差异** | 有映射 | ⚠️ **缺NULL匹配特殊处理** |
| `SYSDATE` → `CURRENT_TIMESTAMP` | 语义确认 | ❌ 未转换 | ❌ 缺失 |
| `SYSTIMESTAMP` → `clock_timestamp()` | 墙钟时间 | ❌ 未转换 | ❌ 缺失 |
| `ROWNUM` → `LIMIT/row_number()` | 分页语义 | ✅ 部分 | 🟡 |
| `DUAL` | 通常省略 | ❌ 残留 4 处 | ❌ P2-6 未完成 |
| `MINUS` → `EXCEPT` | 集合语义 | ❌ 未处理 | ❌ 缺失 |
| `(+)` → ANSI JOIN | **条件归属拓扑** | ✅ P2-3 结构化 | ✅ |
| `CONNECT BY` | 递归 CTE | ❌ 未处理 | ❌ 缺失 |
| `TRUNC(date)` → `date_trunc` | 粒度确认 | ✅ 有映射 | ✅ |

## 三、高风险缺口（按手册 §13.1 / §24 优先级）

| # | 缺口 | 手册依据 | 影响 | 建议 |

## 五、缺失规则（按手册章节）

### 5.1 关键缺失（应优先实现）

1. **§7.1** `SYSDATE` → `CURRENT_TIMESTAMP` / `SYSTIMESTAMP` → `clock_timestamp()`
2. **§7.1** `DECODE` NULL 匹配特殊处理（`DECODE(x, NULL, ...)` ≠ `CASE WHEN x IS NULL`）
3. **§7.1** `CONNECT BY` → 递归 CTE
4. **§7.2** 空字符串=NULL 字段级策略
5. **§8.4** `SELECT INTO STRICT` 语义保留
6. **§11.2** DBMS_SQL 生命周期处理
7. **§13.1** `RAISE_APPLICATION_ERROR` → `RAISE EXCEPTION`
8. **§13.2** Function 内 `COMMIT/ROLLBACK` 检测
9. **§7.3** 变量名与列名冲突检测

### 5.2 次要缺失

1. **§5** `BINARY_FLOAT/DOUBLE` 映射
2. **§5** `TIMESTAMP WITH TIME ZONE` 映射
3. **§5** `INTERVAL` 映射
4. **§7.1** `MINUS` → `EXCEPT`
5. **§11.4** `DBMS_OUTPUT` → `RAISE NOTICE`
6. **§12** 关联数组 `INDEX BY` 处理
7. **§15.3** ENUM 类型映射
8. **§15.3** VARRAY 类型映射

### 6.2 需改进

| **语义差异** | 空字符串策略、DECODE NULL、SELECT INTO STRICT |

1. **短期（P5-2~P5-4）**：完成 P2-6 (`SYSDATE`/`SYSTIMESTAMP`)、补充 `DECODE` NULL 处理、实现 `SELECT INTO STRICT`

3. **长期（T26）**：DBMS_SQL 专项
4. **验证补全**：L5 语义一致性、L6 业务回归用例（L4）、L7 性能测试
